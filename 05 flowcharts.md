# 5. Flowcharts — Amanta Collection

Three flowcharts are required by the coursework: Registration/Login, Checkout, and Order Fulfilment. Each uses standard flowchart symbols (Start/End = oval, Process = rectangle, Decision = diamond, Connectors = arrows). Diagram image files are provided in `/diagrams/`.

---

**To edit these further in draw.io (diagrams.net):**
1. Go to https://app.diagrams.net
2. Choose a blank diagram
3. Recreate the shapes shown in the PNG images above using the Flowchart shape category (Oval = Start/End, Rectangle = Process, Diamond = Decision)
4. Export as PNG/SVG when done
